# XCover Android Auto receiver v0.2.0

Battery-drain fix for the dedicated receiver's unplugged state.

## Fixed

- automatic Native Android Auto Bluetooth wake retries now require external power;
- removing external power immediately cancels the automatic retry job;
- Bluetooth auto-start no longer rearms Native Android Auto while the receiver is unplugged;
- the parked-use **Connect** action remains available as an explicit manual attempt;
- the startup partial wake lock now uses the documented ten-second timeout instead of ten minutes.

The fault was reproduced on the physical XCover: while unplugged with the screen off, the previous build performed 704 automatic retry cycles over 9 hours 35 minutes and lost 38–39% charge. Battery diagnostics reported `Good` health and an estimated 3,852 mAh capacity against the 4,050 mAh design capacity, while the wireless subsystem generated thousands of wake events.
