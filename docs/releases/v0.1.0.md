# XCover Android Auto receiver v0.1.0

First public snapshot of the dedicated Samsung Galaxy XCover Pro receiver project.

## Included

- software-only wireless Android Auto reception through Bluetooth HFP SLC and 5 GHz Wi-Fi Direct;
- reproducible Open Headunit patches pinned to upstream commit `581a55f26fe74b2c93eae5778ddcd683eb08b113`;
- automatic boot and stable external-power startup behavior;
- fixed landscape dedicated UI with Android Auto, front/rear TPMS, and settings;
- BLE TPMS discovery, local front/rear assignment, stale-data handling, and compact projection alerts;
- programmable side-key rain touch lock using `keyCode 1015`;
- English base copy, Brazilian Portuguese, and maintained compact-alert locales;
- sanitized device evidence, rollback scripts, and complete agent/maintainer instructions.

```text
Package: com.andrerinas.headunitrevived.hfpslc
Version: 3.2.0-hfp-slc (91)
Certificate SHA-256: bc31e8db447636a30d2f1f97bd8ca190b110c33395d2321690a995171e72eac1
```

This is an Android debug-signed manual sideload build. Verify `SHA256SUMS.txt` before installation. Future APK updates must use the same certificate or Android will reject an in-place update.

## Verified scope

- Exact APK hash verified from the installed package on Samsung `SM-G715U1`.
- Wireless Android Auto projection verified with an Android phone whose model is intentionally withheld.
- Unit tests and `assembleGithubDebug` passed from a clean application of both patches.
- Dedicated home, simulated TPMS alert, power behavior, and physical side-key lock/unlock verified on the XCover.
